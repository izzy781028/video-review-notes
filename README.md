# 影片修改對齊工具

**直接使用：** https://izzy781028.github.io/video-review-notes/ （手機打開後「加入主畫面」）

一個網頁檔（`index.html`）：載入影片、暫停、在當下的時間碼用**文字或語音**記下修改意見，AI 把口語整理成具體的執行指示，最後匯出成**含截圖的修改文件**、Excel 表格或 Premiere 標記。電腦、手機都能用，不用安裝。

## 功能

| | |
|---|---|
| 載入影片 | 拖進來／選檔（手機可從相簿、檔案 App 選或直接拍），或貼 Dropbox／直連網址。影片只在自己的裝置播放，不會上傳 |
| 時間碼 | 依 FPS（23.976～60）與起始 TC 顯示 `HH:MM:SS:FF`，可逐格、逐秒移動 |
| 逐點意見 | 暫停的那一格自動記下時間碼和截圖 |
| 整體意見 | 不針對特定時間碼、針對整支片的意見（勾「整體意見」或按 `G`） |
| 語音輸入 | 繁體中文、中英夾雜。三種引擎可選（見下方） |
| AI 潤飾 | Claude 把口語、贅字整理成「改哪裡、改成什麼」的指示，不清楚的地方標【待確認】；保留原始口述可隨時換回 |
| 修改清單 | 點時間碼跳回該格、直接在清單上改字、標記已修改、時間軸上有標記點 |
| 匯出 | **Word 文件（每個時間碼配全解析度截圖＋文字）**、HTML 報告／PDF、複製到 Excel／Google 試算表、CSV、Premiere 標記 XML、SRT、JSON |
| 多人審片 | 每個人匯出 JSON，其他人用「匯入別人的意見」合併成一份 |
| 自動存檔 | 意見存在瀏覽器裡，同一支影片下次打開會接著用 |

## 快速開始（電腦）

1. 用 Chrome 或 Edge 打開 `index.html`（直接雙擊即可）。
2. 按右上「⚙ 設定」：填審片人名字、選語音引擎並填 API Key、填常講的專有名詞。
3. 把影片拖進來，播放。看到要改的地方：
   - `V`：暫停並開始錄音，講完再按 `V` → 自動辨識 → 自動 AI 潤飾
   - `Enter`：暫停並打字
   - `G`：整體意見
   - `Ctrl/⌘ + Enter` 儲存，`Esc` 取消
4. 右上「匯出 ▾」選「文件（Word，含截圖）」。

其他快捷鍵：`Space` 播放/暫停、`←` `→` 前後一格、`Shift + ←/→` 前後一秒、`J` `K` `L`、`[` `]` 跳到上/下一則意見。

## 語音辨識：怎麼做到中英夾雜也準

| 引擎 | 適合 | 說明 |
|---|---|---|
| **ElevenLabs Scribe v2**（預設、推薦） | 中英夾雜、專有名詞多 | 可以把品牌名、術語填進「專有名詞」，最多 100 個，辨識時會優先套用 |
| OpenAI gpt-4o-transcribe | 備案 | 專有名詞會放進提示詞 |
| 瀏覽器內建 | 免費、即時出字 | 中英夾雜較弱，手機上不一定穩 |

- 不管哪個引擎，結果都會經 OpenCC 轉成**台灣繁體與用語**（例：视频 → 影片）。
- 準確度最大的差別在「專有名詞」：把客戶品牌、產品名、常講的英文（Logo、Super、B-roll、CTA…）填進去。
- 語音辨識後會自動交給 Claude 潤飾，所以錄音時照平常講話就好。

### AI 潤飾

- 需要 Anthropic API Key（[console.anthropic.com](https://console.anthropic.com)）。模型可選 Opus 5.5（最仔細，預設）、Sonnet 5.5、Haiku 5.5（最快最便宜）。
- 會附上那一格的截圖，讓 Claude 把「這裡」「這個字」對應到畫面上的具體位置，但只整理原話、不會自己加修改。
- 不想自動潤飾：到設定取消「語音辨識完自動潤飾」，需要時再按「✨ AI 潤飾」。

API Key 只存在你自己裝置的瀏覽器裡，錄音／文字直接送到你選的服務，不經過其他伺服器。

## 在外面用手機看片、記意見

手機要用麥克風，網頁必須是 **https** 網址（直接開手機裡的檔案不行）。把 `video-review-notes` 資料夾放到任一個靜態網站服務上即可，例如：

- **Netlify Drop**（最簡單）：到 app.netlify.com/drop 把資料夾拖進去，馬上得到一個 https 網址。
- GitHub Pages、Cloudflare Pages 也可以。

拿到網址後，用手機 Safari / Chrome 打開 →「加入主畫面」，之後就像 App 一樣全螢幕開啟。設定（API Key、專有名詞）手機要另外填一次。

手機介面：底部固定三顆大按鈕（語音／文字／整體意見），影片下方有 −1秒、−1格、+1格、+1秒、上/下一則意見；匯出時會跳出分享選單，可以直接傳到 LINE、Email 或存到檔案。

### 影片怎麼放到手機上，播放才順

**最順：出門前先把「小檔」下載到手機。** 在外面就算網路很差，播放、逐格、跳轉都不卡（只有語音辨識、AI 潤飾需要網路，資料量很小）。

1. 輸出一個 720p 的審片小檔（約 3～5 Mbps，10 分鐘約 300 MB）：
   - Premiere / Media Encoder：H.264、1280×720、位元速率 4 Mbps。
   - 或用 ffmpeg：
     ```bash
     ffmpeg -i 原檔.mov -vf scale=-2:720 -c:v libx264 -preset fast -crf 23 \
       -c:a aac -b:a 128k -movflags +faststart 審片_720p.mp4
     ```
2. 用 AirDrop、LINE Keep、Google Drive / Dropbox App（設成「可離線使用」）傳到手機，存到「檔案」或相簿。
3. 打開工具 → 點「選影片」→ 從檔案或相簿選。

**次選：用連結串流播放。** 把影片放 Dropbox → 分享連結 → 貼到「影片連結」欄位（工具會自動轉成可播放的直連）。
- 4G/5G 播 720p 大約需要 5 Mbps 以上；一定要輸出成 mp4 並加 `+faststart`（Premiere 的 H.264 預設就是），才能邊下載邊播、可以跳轉。
- 放影片的地方要支援「分段下載（Range request）」才能拖時間軸；Dropbox、S3、一般 NAS 都可以。
- Google Drive 的分享連結大多不能直接播放（檔案大時會被擋），建議用 Dropbox 或直接下載。
- 有些伺服器不允許網頁擷取畫面，這時工具仍可播放和記錄，只是沒有截圖，畫面上會提示。

**意見記在手機上，回到電腦怎麼接著用？** 手機「匯出 → JSON」傳給自己，電腦打開同一支影片後「匯出 → 匯入別人的意見」即可合併。

## 匯出格式說明

| 格式 | 用途 |
|---|---|
| Word（含截圖） | 給剪接師或客戶的修改文件：整體意見在前，逐點修改表格含截圖、時間碼、類別、內容、狀態 |
| HTML / 列印 PDF | 同上內容，網頁版或存成 PDF |
| 複製表格 / CSV | 貼進 Excel、Google 試算表追蹤進度（含原始口述欄位） |
| Premiere 標記 XML | Premiere「檔案 → 匯入」，會建立一條含影片和所有標記的序列（找不到影片時指定原檔即可），標記註解就是修改內容 |
| SRT | 拖進播放器或剪輯軟體，把意見疊在畫面上看 |
| JSON | 合併多人意見、換裝置繼續 |

截圖會在匯出時回到每個時間碼重新擷取（最高 1280 寬），所以文件裡的圖是清楚的。

## 限制

- 時間碼以非丟格（NDF）計算；29.97 / 59.94 影片若時間碼是丟格制，長片後段會有幾格誤差。
- 瀏覽器只能播放它支援的格式：mp4（H.264）最保險，ProRes .mov 在 Chrome 上通常無法播放，請先輸出審片小檔。
- 意見存在各自瀏覽器裡，換瀏覽器或清除網站資料會不見，記得匯出 JSON 備份。
